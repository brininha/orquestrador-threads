# Sistemas Operacionais: leitores e escritores

Repositório destinado ao exercício programa 2 (EP2) da disciplina de Sistemas Operacionais. O projeto implementa um simulador com 100 threads concorrentes para analisar e comparar o desempenho entre o acesso via exclusão mútua simples e o algoritmo clássico de Leitores e Escritores atuando sobre uma base de dados em memória RAM.

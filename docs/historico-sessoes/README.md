# Histórico de sessões

Esta pasta serve como o **diário de bordo** do trabalho de Sistemas Operacionais. Aqui guardamos o estado do projeto ao final de cada turno de desenvolvimento.

O objetivo é garantir que qualquer membro do grupo consiga dar continuidade ao trabalho sem perder o contexto do que já foi feito, evitando que o código seja quebrado ou sobrescrito com lógicas antigas.

## Como registrar o fim da sua sessão
1. Copie o prompt que está em `docs/contexto-ia/handoff-template.md`.
2. Envie para a IA que estava auxiliando no seu código.
3. Crie um novo arquivo nesta pasta contendo o resumo gerado pela IA.

## Padrão de nomenclatura
Para mantermos a ordem cronológica e sabermos quem fez o quê, nomeie os arquivos seguindo este padrão:
`AAAA-MM-DD-frente-0X-nome.md`

**Exemplos:**
- `2026-11-08-frente-01-dados-io-fulano.md`
- `2026-11-08-frente-03-concorrencia-ciclano.md`

# Guia de atualização de contexto

*   Sempre que a assinatura de um método base for modificada, atualize o arquivo `integration-contracts.md`.
*   Decisões que afetem como o grupo testa a aplicação (ex: escolha da biblioteca de geração do CSV) devem ser anotadas em `decisions.md`.
*   Mantenha seu arquivo `workstream-XX.md` limpo, marcando tarefas como `[x] Concluído` para que a IA não tente re-implementar peças prontas nas próximas conversas.

# Fluxo de desenvolvimento

*   **Branching:** Utilizaremos um fluxo simples baseado no `main`. Cada tarefa deve ser desenvolvida em uma branch separada, nomeada como `feat/T32-mutex` ou `fix/T11-out-of-bounds`.
*   **Commits:** Mensagens curtas, em português, descrevendo "o que" e "por que". Ex: "feat: implementa leitura do bd.txt para array estático".
